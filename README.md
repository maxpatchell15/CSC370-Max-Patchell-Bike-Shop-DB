# CSC370-Max-Patchell-Bike-Shop-DB
CSC370 UVic Course Project: Bike Shop Database

## Project Overview
This project follows the development of a database for a bicycle shop using MySQL. Core logic is to sell bicycles and track inventory. The initial entities to store are bicycle models, individual bicycles, customers, and sales so the shop can identify available stock and review purchase history.

This project is designed to be scalable, but will be developed within the time available, with a primary focus on having clean and simple base logic that meets the provided requirements. Project scope could later expand to repairs, rentals, returns, and parts.

## Requirements
- Store bike brand names and models. 
- Identify each individual bicycle by a unique BikeID relating to its type and listed price.
- Have a unique CustomerID and link it to contact details and purchases.
- Record each sale’s customer, date, bicycles, and actual prices paid.
- Allow customers to purchase multiple bicycles.
- Make sure no bike is sold more than once.
- Preserve a sales history.
